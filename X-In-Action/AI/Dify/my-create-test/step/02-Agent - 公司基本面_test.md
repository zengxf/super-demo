## 02-创建Agent - 公司基本面_test

**入口**
- 工作室 -> Agent -> 创建应用 -> 创建空白应用
  - -> 点"新手适用" -> Agent

**创建**
- 输入名称和描述、选择图标 -> 创建 -> 设置提示词 -> 设置变量
  - 添加**工具** -> SearXNG -> SearXNG 搜索
    - -> 配置 "SearXNG 搜索" 工具 -> **搜索类型 & 时间范围**
  - -> Agent 设置
    - -> 设置 "最大迭代次数" 参数
  - -> 设置模型
  - -> 调试与预览
    - -> 输入相关参数后 -> 聊天框输入 `OK` 即可
  - -> **发布 | 运行 | 访问 API** 即可

**工具**
- **可选择 "工作流" (工具里面的工作流) 和 "MCP"**
