## 11-创建Chatflow - 测试条件_代码_变量聚合

**入口**
- 工作室 -> Chatflow -> 创建应用 -> 创建空白应用
  - -> Chatflow

**创建**
- 输入名称和描述、选择图标 -> 创建 -> 
  - -> "开始" 节点，点击 "+" 按钮 -> 弹出框 -> 节点 -> "**代码执行**"
    - -> 设置 -> 节点名称 & 输入变量 & Py 或 JS 代码 -> 输出变量
    - **调试运行：变量如果是 `开始 / {x} sys.query`**，
      - **可点预览 -> 输入聊天内容**
  - -> "代码执行"，点击 "+" 按钮 -> 弹出框 -> 节点 -> "**条件分支**"
    - -> 设置 IF 判断 -> IF | ELSE -> **Step_3**
  - **Step_3** -> 点击 "+" 按钮 -> 弹出框 -> 节点 -> "**变量聚合器**"
    - -> 设置 -> 变量赋值 -> *最终结果是多选一*
  - -> "变量聚合器"，点击 "+" 按钮 -> 弹出框 -> 节点 -> "**直接回复**"
    - -> 设置 -> 回复 -> 选择 `变量聚合器 / {x} output`
  - -> **发布 | 运行 | 访问 API** 即可

**变量聚合器**
- **最终只输出一个变量，即按顺序设置的第一个不为空的变量**
