# 插件管理


## 插件页面
- 首页 -> 右上 -> **插件**

- http://192.168.3.192/plugins?category=plugins
- http://localhost/plugins?category=plugins

- 左上 -> **插件 `n`** | **探索 Marketplace**
  - **插件 `n`** 表示已安装的插件
  - **探索 Marketplace** 表示插件市场，可搜索 | 安装


## 安装插件
- **腾讯混元**
  - 腾讯混元提供的模型，例如 hunyuan-standard、 hunyuan-standard-256 等等。
- **深度求索**
  - 深度求索提供的模型，例如 deepseek-chat、deepseek-coder。
- **通义**
  - 阿里通义接口。
- **Minimax**
  - Minimax AI 提供的大语言模型、文本嵌入和语音合成服务。
- **Ollama**
  - Ollama。
- **OpenAl-APl-compatible**
  - 兼容 OpenAI API 的模型供应商，例如 LM Studio、llama.cpp 服务。
- **Text Embedding Inference**
  - 用于文本嵌入模型的超快速推理解决方案。
- **Firecrawl**
  - Firecrawl API 集成，用于网页爬取和数据抓取。
- **SearXNG**
  - 开源免费的互联网元搜索引擎。
- **MinerU**
  - MinerU是一款可以在本地部署的将FILES转化为机器可读格式的工具（如markdown、json），可以很方便地抽取为任意格式。


## 配置密匙
- 控制台 -> 右上角 -> 个人头像 -> 「设置」 -> 模型供应商
  - 具体供应商 -> 「设置」 -> 填入 API Key


## 数据来源 - 配置
- 控制台 -> 右上角 -> 个人头像 -> 「设置」 -> 数据来源
  - 可配置 `Jina Reader | Firecrawl | WaterCrawl` 的 API Key
