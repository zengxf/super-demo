# 成员管理


## 添加成员
- 控制台 -> 右上角 -> 个人头像 -> 「设置」 -> **成员**
  - -> 添加 -> 输入邮箱 -> 选择：`成员 | 编辑 | 管理员`
  - -> 发送邀请
  - -> 发送完之后，也可手动**复制邀请链接**
- 邀请链接如下：
  - http://localhost/activate?email=zxf1%40fa.com&token=9739e527-8fe5-4eb4-91e2-4b4522a10abc
  - http://localhost/activate?email=zxf2%40fa.com&token=22d837cb-6b17-4025-8e57-2cbc1b5f0647


## 其他操作
- 成员列表 -> `角色`列
  - -> 改角色，选择：`成员 | 编辑 | 管理员`
  - -> 删除，选择：`移出团队`
